# GrillMe

Read the plan and available evidence first. Identify the decision with the largest downstream effect or uncertainty.

Ask one focused question at a time, give a recommended answer with its reasoning, and wait for the user's response before moving down the next branch. Challenge unsupported assumptions and explain the consequence of a choice. Use available documents or code to answer factual questions before asking the user.

Maintain the emerging decisions and unresolved questions in the conversation. Stop when the user has a workable plan or asks to stop. Summarize the decisions that changed and the remaining uncertainty.

If the user asks to save the result in Company OS, resolve the registered brain and save it with the correct personal/company scope. Do not publish, install tools, create issues, or edit files merely because a plan was discussed.

This skill is self-contained; it does not require a separate /grilling command.
