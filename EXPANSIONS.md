# Add things when the work needs them

Start with saved context and one useful task. Expand when you notice a specific gap.

| Need | Ask your AI |
|---|---|
| Better brand context | "Help me refine our audience and positioning." See the [brand workshop](references/brand-workshop.md). |
| Information from another tool | "Connect the tool we need for this task." See [connections](references/connections.md). |
| A repeated task | "Help me make this easier next time." Level-up can save a prompt, template, or skill. |
| Better recall | "Check whether my brain is working." Audit checks retrieval and usefulness. |
| Stale or conflicting information | "Check this brain for outdated information." Os-audit checks sources and routing. |
| Backup or another computer | "Help me back up this whole brain." See [backup and recovery](references/backup.md). |

Create templates, brand assets, or scripts only when there is something useful to put in them. Register ongoing projects in `projects/README.md`. Keep one authoritative home for each fact or rule, with links from other places.

Scheduled jobs are optional. Prove a workflow works manually first. Before scheduling it, agree on inputs, output location, permissions, costs, failure notification, and how to stop it. Record the schedule and owner in the project's instructions. A skill named "daily" is not evidence of a schedule.

The [operator framework](references/operator-framework.md) is an optional discussion aid. Its heuristics do not impose prerequisites on ordinary tasks.

The public installation handoff lives at https://www.leanlabs.com/unbound/brain.md. This folder is the kit it installs.
